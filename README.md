以下の要件に基づき、アメフト部向けのコンディショニング管理Webアプリ（SPA）を作成してください。

### 1. デザイン・UIスタイル
- カラーパレット：
  - 背景色：白（#FFFFFF）および薄いグレー
  - メインカラー：レッド（#ef3434）
  - アクセントカラー：ダークブラウン/ブラック（#2f1e1e）、グレー
- デザイン：モダンで清潔感があり、スポーツチーム向けの直感的なUI
- レスポンシブ対応：選手用画面はスマートフォン最適化、コーチ用管理画面はPC大画面最適化

### 2. 画面構成と機能

#### A. 画面切替ヘッダー
- 画面上部に「選手用入力フォーム」「コーチ用ダッシュボード」を切り替えるタブまたはボタンを配置

#### B. 選手用画面（コンディション入力 & フィードバック）
1. **入力フォーム**
   - 氏名選択（ドロップダウン：山田 太郎, 佐藤 健太, 鈴木 大輔, 田中 翔, 高橋 陸, 伊藤 翼）
   - 身体の痛み・張り・違和感（複数選択チェックボックス：なし, 首, 肩, 腰, 股関節, 膝, 足首, その他）
   - 主観的疲労度（1〜10のスライダーまたはラジオボタン、1:良好 〜 10:限界）
   - 睡眠時間（数値入力、0.0〜24.0、0.5単位）
   - 食事回数（数値入力、0〜5回以上）
   - 「送信」ボタン
2. **送信完了フィードバック表示**
   - 送信後、入力データに基づき即座にメッセージカードを表示
     - 【良好（緑）】：「良いコンディションです！今日の練習も頑張りましょう。」
     - 【注意（黄）】：「睡眠時間が不足気味です。練習後のリカバリーを念入りに。」
     - 【警告（赤）】：「疲労が溜まっています（または痛みがあります）。練習前にS&Cコーチやトレーナーに相談してください。」

#### C. コーチ用画面（管理ダッシュボード）
1. **サマリーエリア**
   - 「本日の入力者数（例: 6/80名）」カード
   - 「要注意（赤）人数」カード（要対応の人数を大きく表示）
2. **コンディション一覧テーブル**
   - カラム：日付 / 氏名 / 疲労度 / 睡眠時間 / 食事回数 / 痛み・違和感 / ステータス
   - **条件付き背景色（ハイライト）**：
     - 赤（#FEE2E2）：疲労度8以上 OR 睡眠5時間未満 OR 痛み「あり（「なし」以外）」
     - 黄（#FEF3C7）：上記以外で、疲労度6〜7 OR 睡眠5〜6時間
     - 白/緑（#ECFDF5）：上記以外（良好）
3. **フィルター & ソート**
   - 「要注意（赤）のみ表示」切り替えトグル
   - 疲労度の降順・昇順ソート機能
