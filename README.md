# アメフト部 コンディショニング管理アプリ

選手が毎日の体調（疲労度・睡眠・食事・痛み）を入力し、コーチがチーム全体の状態を一目で確認できるWebアプリです。

- 仕様の詳細：[`docs/要件定義書.md`](docs/要件定義書.md)

## 画面
| 画面 | 内容 | 最適化 |
|---|---|---|
| 選手用入力フォーム | 体調を入力 → 送信後に 良好/注意/警告 のメッセージを表示 | スマホ |
| コーチ用ダッシュボード | 入力者数・要注意人数のサマリー、色分けされた一覧表、赤のみ表示・疲労度ソート | PC |

画面上部のタブで切り替えます。

## 技術構成
- Next.js（App Router）/ TypeScript / Tailwind CSS
- ホスティング：Vercel
- データ保存：ブラウザ内（localStorage）。DB・ログインは未使用のため、**環境変数の設定は不要**です。
  - 同じ端末・ブラウザ内でのみデータが残ります。部員全員で共有するには、今後 Neon（DB）と Neon Auth（ログイン）の導入が必要です。
  - ダッシュボード右上の「データを初期状態に戻す」でダミーデータに戻せます。

## フォルダ構成
```
src/
  app/            画面の入口（page.tsx）とレイアウト・共通スタイル
  components/     Header（タブ）/ PlayerForm（選手入力）/ CoachDashboard（コーチ画面）
  lib/            conditioning.ts（ステータス判定ルール・初期データ）
docs/             要件定義書
```

## デプロイ（Vercel）
1. Vercel で「Add New → Project」からこのGitHubリポジトリを選ぶ
2. Framework は自動で「Next.js」になるので、そのまま「Deploy」
3. 環境変数の追加は不要
