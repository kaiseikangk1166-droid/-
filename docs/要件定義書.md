# 要件定義書：アメフト部 コンディショニング管理Webアプリ

## 1. デザイン・UIスタイル
- 背景色：白（#FFFFFF）および薄いグレー
- メインカラー：レッド（#ef3434）
- アクセントカラー：ダークブラウン/ブラック（#2f1e1e）、グレー
- モダンで清潔感のある、スポーツチーム向けの直感的なUI
- 選手用画面はスマートフォン最適化、コーチ用管理画面はPC大画面最適化

## 2. 画面構成と機能

### A. 画面切替ヘッダー
- 画面上部に「選手用入力フォーム」「コーチ用ダッシュボード」を切り替えるタブを配置

### B. 選手用画面
1. 入力フォーム
   - 氏名（ドロップダウン：山田 太郎, 佐藤 健太, 鈴木 大輔, 田中 翔, 高橋 陸, 伊藤 翼）
   - 身体の痛み・張り・違和感（複数選択：なし, 首, 肩, 腰, 股関節, 膝, 足首, その他）
     - 「なし」と部位は同時に選べない（部位を選ぶと「なし」は外れる）
   - 主観的疲労度（1〜10のスライダー、1:良好 〜 10:限界）
   - 睡眠時間（0.0〜24.0、0.5単位）
   - 食事回数（0〜5回以上）
   - 「送信」ボタン
2. 送信後のフィードバックカード
   - 良好（緑）：「良いコンディションです！今日の練習も頑張りましょう。」
   - 注意（黄）：「睡眠時間が不足気味です。練習後のリカバリーを念入りに。」
   - 警告（赤）：「疲労が溜まっています（または痛みがあります）。練習前にS&Cコーチやトレーナーに相談してください。」

### C. コーチ用ダッシュボード
1. サマリー
   - 本日の入力者数（例：6 / 80名）
   - 要注意（赤）人数
   - ※集計対象日は「記録がある最新の日付」。選手が今日入力すれば今日が対象になる
   - ※同じ選手が同日に複数回入力した場合は1名として数える
2. コンディション一覧テーブル
   - カラム：日付 / 氏名 / 疲労度 / 睡眠時間 / 食事回数 / 痛み・違和感 / ステータス
3. フィルター & ソート
   - 「要注意（赤）のみ表示」トグル
   - 疲労度の降順・昇順ソート

## 3. ステータス判定ルール
| ステータス | 条件 | 行の背景色 |
|---|---|---|
| 赤（警告） | 疲労度8以上 OR 睡眠5時間未満 OR 痛みあり（「なし」以外） | #FEE2E2 |
| 黄（注意） | 赤以外で、疲労度6〜7 OR 睡眠5〜6時間（5.0以上6.0以下） | #FEF3C7 |
| 緑（良好） | 上記以外 | #ECFDF5 |

## 4. データ保存
- 現段階ではDB・ログインは使わず、ブラウザ内（localStorage）に保存する
  - 同じ端末・同じブラウザでのみデータが共有される
  - 部員全員でデータを共有するには、将来 Neon（DB）＋ Neon Auth（ログイン）への移行が必要
